# Velocity Motors Pakistan – Online Bike Showroom

Premium dark-themed multi-page website for a Pakistani motorcycle showroom.

## Pages
- **index.html** – Home (Hero, Categories, Featured Bikes, Why Us, Testimonials)
- **bikes.html** – Full inventory with Search, Brand/Category filters & Sorting
- **bike-detail.html** – Individual bike page with specs, EMI calculator, related bikes
- **about.html** – Company story, mission, vision
- **book.html** – Test Ride booking form (with validation & success message)
- **contact.html** – Contact info + form

## Features
- Fully responsive (mobile-first)
- Dark premium theme (Black + Electric Red)
- Working filters & search on Bikes page
- EMI Calculator on detail page
- WhatsApp floating button
- Smooth hover effects
- Pakistan-specific popular models & realistic 2026 prices

## How to Use
1. Download the entire `velocity-motors` folder
2. Open `index.html` in any modern browser
3. Or host it on Netlify / Vercel / GitHub Pages / any web host

## Tech
- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript
- Font Awesome icons
- Unsplash placeholder images (replace with real bike photos later)

## Brands Included
Honda, Yamaha, Suzuki, Unique, Road Prince, Super Power, Jolta (Electric)
